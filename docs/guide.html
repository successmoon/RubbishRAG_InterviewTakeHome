🛠️ Engineering Guide: Scientific Probing

How to formulate falsifiable hypotheses, probe the black box, analyze score distributions, and verify improvements empirically.

The Investigation Loop

  1. Observe a Symptom: Run python3 rubbish.py bepar "<query>" and inspect which documents rank at top-1.
  2. Formulate a Falsifiable Hypothesis: e.g., "The retriever ranks document 9002 first because the word 'مالیات' is repeated 12 times in the poison document."
  3. Run Diagnostic Probes: Execute targeted queries with varied lengths, slot values, or synonyms. Every probe is automatically logged to traces/trace.jsonl with exact timestamps and hit scores.
  4. Inspect Specific Traces: Run python3 rubbish.py inspect-trace <TRACE_ID_OR_KEYWORD> to inspect hit scores and rankings in detail.
  5. Plot the Evidence: Run python3 rubbish.py bekesh (or rapchik) to generate scatter and histogram diagrams in plots/.
  6. Implement the Fix: Write the solution in rubbish_rag/ using decorator overrides.
  7. Compare Benchmark Runs: Run python3 rubbish.py compare traces/baseline.json traces/improved.json to verify benchmark shifts side-by-side.

Developer Toolkit & CLI Commands

1. Probing a Single Query (bepar)

python3 rubbish.py bepar "رتبه C1 یعنی چی؟" --topk 5

Output breakdown:

  • doc_id: Document index (IDs ≥ 9000 indicate injected poison documents).
  • bm25: BM25 score assigned by the server.
  • dense: Overlap-based dense score.
  • fused: Server-combined score (naive linear min-max combination).

2. Inspecting Logged Traces (inspect-trace)

python3 rubbish.py inspect-trace "رتبه C1"

Pretty-prints the full retrieval response, score breakdown, and timestamps for matching trace entries in traces/trace.jsonl.

3. Comparing Benchmark Runs (compare)

python3 rubbish.py compare traces/metrics_baseline.json traces/metrics.json

Outputs a side-by-side comparison table of accuracy, answer accuracy, clarify accuracy, and latency percentiles.

4. Running the System-1 Decision Judge (judge & judge-bench)

# Single query decision:
python3 rubbish.py judge "بانک صادرات به رتبه E3 وام میده؟"

# Comprehensive quantitative benchmark:
python3 rubbish.py judge-bench --split test

5. Generating Diagnostic Plots (bekesh)

python3 rubbish.py bekesh

Generates four diagnostic diagrams in plots/:

  • plots/score_spread.png: Top-1 vs Top-5 score gap per query. Flat spreads indicate high ambiguity or uninformative rankings.
  • plots/length_vs_bm25.png: BM25 scores plotted against chunk length (exposing the severe length penalty bias $b=0.9$).
  • plots/repetition_vs_bm25.png: Demonstrates how keyword-stuffed poison documents exploit the BM25 formula.
  • plots/report_card.png: Your candidate report card with accuracy and latency metrics.

Persian Normalization Blueprint

Persian text in credit scoring contains several common variations that break naive string matching:

Category Raw Variation Canonical Target Why it Matters
Digits ۲۵۰ (FA) / ٢٥٠ (AR) 250 (ASCII) Credit threshold numbers must match across scripts.
Arabic Letters ي, ك, ة ی, ک, ه Users type on Arabic or Persian keyboards interchangeably.
Half-Space (ZWNJ) می‌شود (ZWNJ: \u200c) Normalized whitespace Prevents tokens from splitting or merging arbitrarily.
Colloquial Forms میشه, چیه, چقد, رتبم می‌شود, چیست, چقدر, رتبه من User colloquial queries must match formal FAQ rows.

Entity Slot Mining

In this domain, swapping a single entity can completely invert the correct answer:

  • Bank: ملی, صادرات, تجارت, توسعه صادرات, ملت, سپه, پاسارگاد (each bank sets its own loan approval policy).
  • Rank Code: A1, A2, A3, B1, B2, B3, C1, C2, C3, D1, D2, D3, E1, E2, E3.
  • Persona: حقیقی (individual, score 250–900) vs حقوقی (corporate entity).
  • Debt Type: چک برگشتی, بدهی مالیاتی, تسهیلات معوق, محکومیت‌های قضایی.
  • Distinctive Numbers: 250 (minimum credit score threshold), 24 (hours), 5 (years of credit history).

Clarification Gating Rules

When an ambiguous query is received, the resolver must output the clarification contract:

{
  "status": "clarify",
  "question": "منظورتان بدهی تسهیلاتی (بانکی) است، یا بدهی مالیاتی و چک؟",
  "options": ["بدهی تسهیلاتی / وام", "بدهی مالیاتی", "چک برگشتی", "نمی‌دانم"]
}
