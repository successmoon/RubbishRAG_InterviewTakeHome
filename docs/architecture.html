3. Scoring Mathematics in the Black Box

Linear Score Fusion Distortion

The black-box server combines sparse BM25 and overlap dense scores using naive min-max scaling:

fused = 0.5 * (bm25 / max(BM25)) + 0.5 * (dense / max(Dense))

Why this fails: BM25 and dense scores follow completely different probability distributions. A single extreme outlier score compresses the entire score space, causing lower-ranked hits to cluster artificially.

The remedy: Implement Reciprocal Rank Fusion (RRF) client-side: 

RRF_score(d) = Σ_m [ 1 / (60 + rank_m(d)) ]

Aggressive BM25 Document Length Penalty

The BM25 formula in the server is parameterized with $k_1 = 1.2$ and $b = 0.9$:

denom = f + k1 * (1 - b + b * (doc_len / avgdl))

Because $b = 0.9$ is excessively high without a BM25+ floor, thorough answers that explain credit rules in detail are severely penalized compared to short, uninformative fragments.

4. The 10 Observed Failure Modes & Investigation Areas

1. Linear Fusion Distortion

Min-max normalization distorts relative ranks when outlier scores occur. Replace with rank-based fusion (RRF).

2. BM25 Length Bias

High $b=0.9$ penalizes informative answers. Needs length-binned compensation and analysis via diagnostic plots.

3. Adversarial / Poison Documents

Keyword-stuffed fake documents exist in the index (doc IDs ≥ 9000). Grounding against corpus/test.csv prevents citation.

4. Persian Script Variations

Digits (۲۵۰ vs 250), Arabic characters (ي/ك/ة), and colloquial forms (میشه vs می‌شود) require canonical normalization.

5. Fragmented Chunking

Fixed 300-char slices sever numbers from their units and drop category headers. Design metadata-aware chunks.

6. Bag-of-Words Reranker Trap

Simple token overlap favors repetitive keyword spam over precise credit entities. Implement slot-aware scoring.

7. Ambiguity Resolution Gating

Queries missing required decision entities should trigger the clarification contract rather than hallucinating answers.

8. Polarity & Negation Sensitivity

Negation particles (نمی‌شود vs می‌شود) are ignored by bag-of-words counters, leading to opposite conclusions.

9. Context Redundancy

Multiple chunks from the same document flood the top-k window, diluting context. Implement deduplication.

10. Fact Verification & Grounding

Subtle metric discrepancies between candidates and reference facts require grounding against verified corpus records.
