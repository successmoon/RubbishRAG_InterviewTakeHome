📖 Metrics & Information Retrieval Glossary

A concise, mathematically precise glossary of the evaluation metrics, search formulas, and calibration concepts used across the RubbishRAG benchmark.

1. Information Retrieval (IR) Metrics

Hit@K (Hit-Rate at Rank K)

Definition: The fraction of queries for which at least one acceptable relevant (gold) document is present within the top-$K$ retrieved candidates. 

Hit@K = (1 / |Q|) * Σ 𝟙( ∃ d ∈ Cites[:K] such that d ∈ Gold(q) )

In RubbishRAG: Answer queries are officially scored on Hit@3 (gold document cited within the first three citations).

MRR (Mean Reciprocal Rank)

Definition: The average of the reciprocal ranks of the first relevant document retrieved across all queries. 

MRR = (1 / |Q|) * Σ ( 1 / rank_first_gold(q) )

If the first gold document appears at position 1, reciprocal rank is $1.0$; if at position 2, $0.5$; if position 3, $0.33$. If not in top-$K$, it is $0.0$.

nDCG (Normalized Discounted Cumulative Gain)

Definition: Measures ranking quality accounting for the graded position of all relevant documents, penalizing relevant items that appear late in the list. 

DCG@K = Σ ( rel_i / log2(i + 1) )
nDCG@K = DCG@K / IDCG@K

Where IDCG@K is the ideal DCG obtained by sorting items in perfect relevance order.

Reciprocal Rank Fusion (RRF)

Definition: An unsupervised rank aggregation method that combines multiple independent retrieval rankings (e.g. sparse BM25 and dense embeddings) based on reciprocal rank order rather than arbitrary score magnitudes: 

RRF_score(d) = Σ_m [ 1 / (k + rank_m(d)) ]

where $k$ is a smoothing constant (standard default: $k = 60$). RRF is robust against outlier scores and probability distribution mismatches.

2. Calibration & Decision Metrics

Brier Score

Definition: A strictly proper scoring rule that measures the mean squared error between predicted probabilities and actual binary outcomes: 

Brier = (1 / N) * Σ (p_i - y_i)²

A Brier score of $0.0$ indicates perfect probabilistic foresight. A score of $0.25$ represents uninformative coin-flip guessing for balanced binary outcomes.

ECE (Expected Calibration Error)

Definition: The weighted average difference between predicted confidence and empirical accuracy across $M$ probability bins: 

ECE = Σ_m ( |B_m| / N ) * | acc(B_m) - conf(B_m) |

When a model reports $80\%$ confidence on a bin, exactly $80\%$ of those samples should be correct. Lower ECE values (<0.05) indicate well-calibrated confidence estimates.

Selective Prediction & Risk-Coverage Curve

Definition: In high-stakes credit domains, models can choose to abstain or escalate when confidence falls below threshold $\theta$.

  • Coverage: Fraction of queries processed without human or secondary escalation.
  • Selective Risk / Error: Error rate calculated exclusively over accepted predictions.

3. System & Efficiency Metrics

Latency Percentiles (p50, p95, p99)

Rather than relying solely on mean latency, production systems monitor distributional percentiles:

  • p50 (Median): Half of all requests complete within this duration.
  • p95: The 95th percentile, capturing tail latency and sporadic overhead.
  • p99: Worst 1% outlier execution times.

Context Token Savings & Pareto Frontier

Context Token Savings: Percentage reduction in retrieved input tokens passed to generators through dynamic top-$K$ budgeting relative to a static $K=5$ or $K=10$ baseline.

Pareto Trade-off: A solution dominates if it achieves higher accuracy with lower latency and fewer context tokens. If higher accuracy requires greater compute, the curve tracing optimal configurations forms the Pareto frontier.
