🚀 Interactive Web Studio & LangChain Orchestrator

An end-to-end interactive playground and modular LangChain-compatible pipeline with dynamic ambiguity resolution.

1. The Minimalistic Web Studio UI

RubbishRAG includes a built-in, lightweight Web Studio playground. You can launch it with a single command:

python3 rubbish.py ui --port 8000

Then navigate to http://localhost:8000/ui (or http://localhost:8000/).

Studio Capabilities

Live Mode Switching

Switch dynamically between Naive RubbishRAG (baseline) and Fixed Orchestrator to visually observe the performance gap.

Interactive Clarification

When an ambiguous query is submitted (e.g. بدهی دارم), the UI displays clickable option buttons. Clicking an option dynamically resolves the ambiguity!

Score Inspection

Inspect raw BM25, Dense, Fused, and Rerank scores per retrieved document hit, alongside suspicious distractor warnings.

2. Interactive Terminal Clarification Chat

If you prefer testing directly in your shell, RubbishRAG includes a multi-turn clarification loop:

python3 rubbish.py chat

3. LangChain LCEL-Compatible Orchestrator

The pipeline is packaged as a modular orchestrator in rubbish_rag/orchestrator.py implementing the standard LangChain Runnable interface: 

from rubbish_rag.orchestrator import get_orchestrator

# Initialize the orchestrator
orchestrator = get_orchestrator()

# Standalone execution
result = orchestrator.run("رتبه C1 یعنی چی؟")
print(result["brief"])
print("Citations:", result["cites"])

# Standard LangChain Runnable invocation
response = orchestrator.invoke({"query": "بانک صادرات به رتبه E3 وام میده؟"})
print("Response:", response["brief"])

4. API Server & Swagger Documentation

The backend is fully accessible via OpenAPI endpoints when running the server:

  • Interactive Swagger UI: http://localhost:8000/docs
  • ReDoc Reference: http://localhost:8000/redoc
  • Health Check Endpoint: GET /health
  • Retrieval Endpoint: POST /retrieve
  • Submission Scoring: POST /submit
  • Studio Query API: POST /studio/query
