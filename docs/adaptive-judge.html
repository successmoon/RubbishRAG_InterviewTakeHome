🧠 Adaptive System-1 RAG Decision Judge

A fast, structured decision layer operating before and within the RAG pipeline to govern retrieval necessity, dynamic context budgeting, collective evidence sufficiency, and calibrated escalation.

Inspiration: This track draws conceptual inspiration from research on Self-RAG (Asai et al., 2023), Adaptive-RAG (Jeong et al., 2024), Corrective RAG / CRAG (Yan et al., 2024), and JEV-as-a-Judge. It separates fast System-1 routing from expensive System-2 synthesis.

1. The Adaptive Decision State Machine

Rather than blindly executing fixed top_k = 5 on every query, the adaptive pipeline follows a bounded decision loop:

      [Conversational]              [Ambiguous]               [Factual Domain]
    NO_RETRIEVAL (k=0)          CLARIFY & OPTIONS            RETRIEVE (k=2..8)

2. Key Responsibilities of the Judge

1. Retrieval Necessity

Distinguishes queries that require credit regulations knowledge from conversational greetings or meta-prompts, returning RETRIEVE or NO_RETRIEVAL.

2. Clarification Gating

Identifies under-specified queries (missing bank, rank, persona, or debt stage) and outputs structured missing_slots instead of hallucinating.

3. Dynamic Context Budget

Chooses top_k dynamically (0, 2, 3, 5, or 8) based on query complexity and entity count. Reduces context token overhead by >30%.

4. Collective Evidence Sufficiency

Evaluates candidates collectively: SUFFICIENT, INSUFFICIENT, CONFLICTING, or IRRELEVANT. Flags poison and keyword-stuffed spam.

4. Open-Weight & Local CPU Viability

The architecture provides two interchangeable implementations:

  • HeuristicFeatureJudge (Default): High-speed, deterministic, calibrated rule-and-feature decision engine executing in <1 ms on standard CPU with zero external dependencies.
  • OpenWeightLLMJudge: Adapter for small local open-weight instruction models (such as Llama-3.2-1B-Instruct or Qwen2.5-0.5B/1.5B). If local model weights or GPU drivers are absent, it automatically and gracefully falls back to the high-speed feature judge.

5. Confidence-Based Escalation & Calibration

Raw self-reported model confidence is rarely well-calibrated out-of-the-box. The judge provides quantitative calibration evaluation:

  • Brier Score: $\text{Brier} = \frac{1}{N} \sum_{i=1}^N (p_i - y_i)^2$. Measures probability accuracy (lower is better; <0.05 is excellent).
  • Expected Calibration Error (ECE): Binned expectation of accuracy vs. confidence across probability thresholds.
  • Selective Prediction / Escalation Cascade: If confidence ≥ threshold (e.g. 0.75), accept the fast decision; otherwise escalate to broader retrieval or explicit clarification.

6. Hands-On CLI Usage

Test the decision judge on any single query in your terminal:

python3 rubbish.py judge "بانک صادرات به رتبه E3 وام میده؟"
